# 🏨 Hotels — каталог отелей на PHP + MySQL

Простой проект на PHP, который выводит карточки отелей в стиле Avito.  
Данные хранятся в базе MySQL, подключение — через `mysqli`.

---

## 📋 Требования

- **XAMPP** (Windows / Linux / macOS) **или** **MAMP** (macOS / Windows)
- PHP **7.4+** (входит в состав XAMPP / MAMP)
- MySQL / MariaDB (входит в состав XAMPP / MAMP)
- Любой современный браузер
